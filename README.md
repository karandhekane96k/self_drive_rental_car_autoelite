# AutoElite (Nandi Cars) - Self-Drive Car Rental Platform

AutoElite is a comprehensive full-stack vehicle rental platform built with the MERN stack and Vite. It features a responsive modern UI, RESTful API architecture, dynamic database integration, and secure user sessions.

## 🚀 Live Demo
* **Frontend (Vercel):** VIew Demo : https://self-drive-rental-car-autoelite.vercel.app/
* **Backend (Render):**

## 🛠️ Tech Stack
* **Frontend:** React.js, Vite, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Security:** JWT (JSON Web Tokens), Bcrypt Password Encryption

## ✨ Key Features
* **Role-Based Access Control:** Separate dashboards and routing for Regular Users and Administrators.
* **Secure Authentication:** Implemented JWT middleware to protect booking routes and maintain user sessions.
* **Dynamic Fleet Management:** Users can browse available cars, while admins can manage the vehicle inventory.
* **Interactive Booking:** Custom UI modals and responsive layouts designed with Tailwind CSS for seamless user navigation.
